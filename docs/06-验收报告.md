## 四、验收过程中发现并修复的缺陷

这一轮的价值主要在这里——都是功能测试跑不出来的：

1. **JWT 令牌不唯一（中高风险）**。payload 只有 `sub/type/exp`，同一秒内多次登录会生成
   **完全相同**的令牌。后果是：用户登出后立刻重新登录，新令牌与刚拉黑的那个一模一样，
   于是"一登录就被判无效"。已加 `jti` 唯一标识。
2. **问数日志越权（高危）**。`/chat/logs` 没有任何用户过滤，普通用户能翻到全公司的
   问数记录（谁、问了什么、反馈状态）。已改为：管理员看全量，普通用户只看自己的。
3. **缓存固化错误结果**。0 行的结果也会被缓存——而 0 行往往是模型没理解对
   （比如维度取值猜错）。缓存它会让错误固化整个 TTL，且看起来毫无异常（耗时 20ms）。
   已改为只缓存有结果的行数 > 0 的问答。
4. **读取他人会话返回 200**。归属校验其实生效了（查不到数据），但返回 `200 + data:null`。
   已改为 404（且用 404 而非 403，避免泄露"该 ID 存在但你没权限"）。
5. **PPL 语义层覆盖缺失**。`bi.fact_ppl` 的指标定义是 **0 个**，`stage`（阶段）维度
   完全没有定义，导致模型不知道 PPL 有哪些度量、也不知道阶段有哪些取值。
   已补 4 个指标 + stage 维度（含 6 个取值）+ 4 条 Few-shot。
6. **部署配置两处硬伤**：web 的 Dockerfile 里 `COPY ../deploy/...` 越出构建上下文
   （Docker 不允许，会直接构建失败）；依赖清单缺 `greenlet`（SQLAlchemy asyncio 必需）
   与 `openpyxl`（台账导入导出），按原样构建出来的镜像起不来、导入功能会 ImportError。

## 五、性能

| 场景 | P50 | P95 | 吞吐 |
| --- | --- | --- | --- |
| 冷缓存（真实模型） | 10.3s | 24.0s | 0.60 次/秒 |
| 缓存预热后 | 0.1s | 0.1s | 111 次/秒 |
| 降级模式 · 10 并发 | 0.5s | 0.7s | 16.5 次/秒 |
| 降级模式 · 50 并发 | 2.1s | 3.2s | 17.6 次/秒 |

结论：**问数延迟的大头是模型往返，索引与视图优化对它几乎没有帮助**——
这也是为什么把缓存作为主要手段。演示或验收前跑一次 `make warmup-cache`。

台账页分页 54ms（验收要求 < 500ms）。

## 六、准确率与已知限制

100 条评测（配额耗尽前跑完的那一轮）：

```
ranking 12/12 · trend 10/10 · edge 10/10 · proportion 8/8 · warning 8/8
filter 9/12 · compare 8/10 · aggregation 8/10
single_entity 5/8 · ppl 4/8 · attribution 1/4
合计 83/100
```

**这 83% 不是模型能力的真实上限**：17 条失败中有 6 条是"全部模型均调用失败"
（即配额耗尽，非语义理解错误），扣除后为 83/94 ≈ 88%。
剩余失败的共性问题是聚合粒度（该出一行汇总却按维度分组、或反之）。

**已知限制**

1. **模型配额已耗尽**。当前所有问数走降级链（`template-fewshot`），
   对 Few-shot 覆盖到的问法仍能正确返回数据（实测 5 个常见问题全部有结果），
   但不再具备泛化能力。补充 Key 后需重跑评测确认真实准确率。
2. **Docker 部署未实测**。本机没有 Docker，`docker-compose.yml` 与两个 Dockerfile
   是按规范编写的静态配置，已修掉两处会导致构建失败/运行报错的问题（见第四节第 6 条），
   但首次部署仍建议先单独验证镜像构建。
3. **E2E 未通过 Playwright 执行**。浏览器下载在验收窗口内未完成；
   核心用例已用浏览器手动走通（登录失败提示、问数 5 步链路、换图、权限收敛、菜单差异），
   Playwright 脚本与配置已交付（`web/e2e/`、`playwright.config.ts`），
   下载完成后 `npx playwright test` 即可运行。
4. **无 CI 流水线**。验证靠 Makefile 脚本手工执行。
5. **数据为造数**。6.2 万行按"先定目标、再反推收入"生成，主线自洽，
   并刻意留了低达成、同比下滑、高风险项目等分析素材。
